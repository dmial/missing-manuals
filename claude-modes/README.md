# claude-modes

Разбор трёх режимов Claude Desktop — Chat, Cowork, Code — и их локальных и облачных вариантов.

Материал пока в HTML, а не в формате заметок этого репозитория: справочник построен вокруг большой сравнительной таблицы, которая в markdown не читается. Канон — файлы здесь; артефакты в приложении Claude Desktop вторичны и при работе из Code разъезжаются с диском.

## Файлы

- [claude-modes-table.html](claude-modes-table.html) — справочник: таблица «режимы × свойства», внутри ячеек подстроки «локально / облако». Плюс разрезы: client tools и server tools (одна задача — два исполнителя), карта источников тулов, четыре контура git-доступа, артефакты и публикация, зачем нужна песочница.
- [claude-modes-article.html](claude-modes-article.html) — статья по мотивам справочника. Черновик, часть разделов — заглушки.
- [claude-modes-open-questions.html](claude-modes-open-questions.html) — трекер открытых вопросов; ответы вписываются туда же, в карточку вопроса.

## Смежные заметки

- [../mcp-protocol.md](../mcp-protocol.md) — сам протокол MCP.
- [../tool-packaging.md](../tool-packaging.md) — куда паковать тулы агента: in-process, CLI, локальный и remote MCP.
- [../agentic-loop.md](../agentic-loop.md) — агентный цикл: модель решает, исполняет код.
- [../claude-code-internals.md](../claude-code-internals.md) — внутренности Claude Code и Agent SDK.

## Правила работы с этим материалом

Факты сверяются с официальной документацией **перед** тем, как попасть в текст; цитаты приводятся дословно. Там, где документация молчит, это помечается явно — утверждения о внутреннем устройстве claude.ai не выдаются за проверенные. Объяснение идёт от пользовательского уровня, технические детали — в скобках. Один факт живёт ровно в одном месте: общие свойства выносятся в заголовки осей, а не повторяются по ячейкам.
