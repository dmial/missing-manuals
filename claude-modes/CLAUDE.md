# claude-modes — правило контекста

Перед любой правкой любого файла этой папки — сначала прочитай целиком ВСЕ файлы серии (`*.html` в этой папке), без напоминаний со стороны пользователя. Причина: главы связаны — общая навигация `.mm-toc`, сквозная нумерация, перекрёстные ссылки «глава N», единая палитра и факты, выверенные по справочнику (`claude-modes-table.html` — главный источник фактов серии). Правка одной страницы без остальных ломает согласованность.

Порядок чтения: справочник (`claude-modes-table.html`) → редактируемая глава → остальные главы.
