Chatдиалог с моделью В полную силу

SaaS-поручения — родной жанр Chat. Корпус за коннекторами, окошка запросов достаточно; файловая среда не нужна. Скиллы плагинов работают и здесь — не доезжают только хуки и суб-агенты.

 Не для этой конфигурации

Файловой среды у Chat нет. К той же папке он дотянется разве что коннектором её сервиса (Drive и т. п.) — а это уже механика колонки «за API».

 Не для этой конфигурации

У Chat нет ни файловой среды, ни git — клон для него не существует.
Coworkагент для файлов и задач С оговорками

Коннекторы, плагины и автономные сессии работают полноценно, но главная сила Cowork — файловая среда — в SaaS-конфигурации простаивает.

 В полную силу

Подключённая папка — родная стихия Cowork. Корпус — рабочая поверхность агента: grep, массовые операции, результаты ложатся на место.

 С оговорками

Файлы клона — стихия Cowork, но сам git ограничен: локальной VM нужен токен (device flow или PAT), облачной сессии — только принесённый PAT, а git в подключённой папке через мост — офлайн, без pull/push.
Codeагент-разработчик С оговорками

Удалённые коннекторы claude.ai Code подхватывает сам — локально при логине в аккаунт, в облачной сессии выбором при старте; свои MCP-серверы и плагины приходят его каналами — .mcp.json и CLI-маркетплейсы (enabledPlugins). Работает, но SaaS-поручения — не его профиль.

 С оговорками

Синкованная папка для Code — обычная папка, работать можно (процедуры возьмёт из .claude/skills в ней же). Но без git нет истории смысла и отката корпуса целиком — у синка лишь версии отдельных файлов; облачным сессиям Code папка недоступна.

 В полную силу

Родная конфигурация Code — клон, ветки, ревью, петля «правка → дифф → коммит» (локально — на твоих ключах, в облаке репозиторий прикрепляется к сессии и push работает из коробки); .claude/skills приезжают с клоном — знания и процедуры одной поставкой.

Если сомневаешься

Проверка от результата

Что должно остаться после работы? Запись в SaaS — Chat; файлы, легшие на место в папке, — Cowork; коммит с объяснением «что и зачем» — Code.

Исполнительский профиль может перебить

Недоверенный контент (письма, чужие PDF) и автономные фоновые задачи тянут в песочницу Cowork; потребность в полном доступе к своей машине с пошаговым контролем — в локальный Code, даже если корпус «не их».
